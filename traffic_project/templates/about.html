About the Project

Smart Traffic Congestion Prediction and Route Recommendation Using Explainable Machine Learning

Predicts congestion (Low / Medium / High / Severe) from historical traffic data, explains the main factors, raises alerts and suggests alternative roads.

Pipeline

Cleaning → duplicate removal → encoding → feature engineering → train/test split → Decision Tree, Random Forest, XGBoost → evaluation → best model deployed in Flask.

Explainability

Global: model feature importance. Per-prediction: each input is reset to a typical value and the change in predicted risk is shown.

Data-leakage handling

Traffic Volume, Average Speed, Travel Time Index and Road Capacity Utilization are excluded from the model because they describe congestion itself. Reported accuracy ({{ (m.models[m.best_model].accuracy*100)|round(1) }}%) is measured without them.

Limitations

• Not real-time: no live traffic feed is connected.
• Route suggestions are model/system suggestions, not navigation instructions; they compare roads in the dataset using the same time and weather, with no map or distance data.
• Accuracy depends on the dataset used.

Tech: Python, Pandas, NumPy, Scikit-learn, XGBoost, Matplotlib, Seaborn, Flask, HTML, CSS, JavaScript.
